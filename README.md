# 中华人民共和国刑法条文检索工具

一个用于本科法学学习的极简法条检索工具：输入关键词，按条文序号列出《中华人民共和国刑法》中所有包含该关键词的条文。

## 功能

- **关键词检索**：输入任意汉字关键词（如"抢劫""正当防卫""缓刑"），列出所有包含该词的条文
- **自动排序**：结果按条文序号从小到大排列，并以 1、2、3…… 数字编号展示
- **关键词高亮**：命中的关键词在条文中以黄色标记
- **罪名标注**：条文前的【】内为罪名，便于识别
- **完全离线**：单个 HTML 文件，无需安装、无需联网、无需命令行

## 使用方法

1. 下载本仓库，或直接下载 `刑法检索工具/刑法条文检索.html`
2. 双击该文件，用浏览器（Edge / Chrome）打开
3. 输入关键词，点击「搜索」或按回车

## 数据来源

- 文本：四川省公安厅公布的《中华人民共和国刑法》全文（2024 年 3 月 1 日起施行）
- 版本：含《中华人民共和国刑法修正案（十二）》
- 规模：共 505 条（452 个基本条文 + 53 个"之一"条文）
- 条文内容以全国人民代表大会公布的正式文本为准

## 技术说明

- 纯前端实现：HTML + CSS + 原生 JavaScript，无任何第三方依赖
- 条文数据以 JSON 形式内嵌在 HTML 中，因此可完全离线运行
- 兼容 Windows 10 / 11 及主流浏览器
